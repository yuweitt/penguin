======================================
 照片跟文字要怎麼放進小小遊樂園？
======================================

【照片】

1. 一共需要 5 張照片，放進 images 這個資料夾裡（跟 index.html 同一層底下的 images 資料夾）。
2. 檔名要跟下面完全一樣（英文小寫）：

   opening.jpg   → 一開始「在開始之前」的開場白畫面
   flappy.jpg    → 第一關 小企鵝飛行記 過關後
   straw.jpg     → 第二關 小朋友下樓梯 過關後
   mario.jpg     → 第三關 忍耐任務 過關後
   balloon.jpg   → 第四關 企鵝氣球大作戰 過關後（也是最後結局畫面）

3. 如果照片是 png 檔也可以，但檔名副檔名要改一致，並且要到 js/config.js
   裡把對應那關的 photo 路徑也一起改成 .png（下面會說在哪裡改）。
4. 哪一關先不放照片也沒關係，畫面會自動顯示一個「照片放這裡」的虛線框，
   不會壞掉、也不會出現破圖。

【文字（每一關過關後想說的話）】

打開 js/config.js 這個檔案，用文字編輯器打開就可以編輯，不需要任何程式知識，
只要照著改雙引號 " " 裡面的文字就好，其他符號（逗號、大括號）都不要動。

1. 開場白的標題和內容，在檔案最上面附近：

   opening: {
     heading: "在開始之前",         ← 這裡是標題，可以改成你想要的
     message: "寫一段給她的開場白吧。", ← 這裡改成你想說的開場白
     photo: "images/opening.jpg",
     note: "",
   },

2. 每一關過關後想說的話，寫在對應那一關的 note 欄位裡，例如：

   flappy: {
     ...
     photo: "images/flappy.jpg",
     note: "",                     ← 在這對雙引號中間打字
   },

   straw、mario、balloon 三關的寫法完全一樣，找到對應的 note: "" 改就好。

3. 改完存檔，重新整理網頁就會生效。

【小提醒】

- 文字裡如果要用到雙引號 " ，前面要加一個反斜線，像這樣：\"
  （不確定的話，盡量避免在句子裡用雙引號就好）
- 5 組通關密碼目前是：54517（開場白）、99821（第一關）、01224（第二關）、
  52517（第三關）、44444（第四關／結局），也是在同一個檔案的最上面可以改。
